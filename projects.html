Detailed Projects List

PROJECT 01

Accessible Portfolio

  • HTML5
  • CSS3
  • WCAG
  • SEO

A multi-page personal portfolio website engineered to demonstrate strict adherence to modern W3C semantic HTML5 standards and WCAG 2.1 AA/AAA accessibility guidelines.

Features complete keyboard and tab navigation, a functional skip link, visible focus rings, high contrast text palette, zero-framework responsive grid layout, accessible form validation with aria-live status messaging, and full Lighthouse SEO and Accessibility target optimizations.

Primary Focus: Structural landmarks, ARIA labeling, keyboard focus management, and SEO metadata integration.

PROJECT 02

Task Manager

  • JavaScript
  • DOM
  • LocalStorage
  • Responsive UI

A browser-based task manager concept created to demonstrate core vanilla JavaScript DOM manipulation, event handling, dynamic state persistence, and responsive UI controls.

Allows users to create, filter, complete, and clear daily tasks with automatic data persistence via browser LocalStorage. Implements accessible keyboard shortcuts, screen-reader friendly status announcements, and touch-optimized buttons.

Primary Focus: Event delegation, client-side data persistence, and dynamic accessible notifications.

PROJECT 03

Healthcare Dashboard

  • UI Design
  • Accessibility
  • Responsive Design
  • Information Architecture

A role-aware dashboard concept designed to prioritize critical medical information and metrics across different hospital administration workflows.

Emphasizes clean information architecture, strong typographic hierarchy, high-contrast data visualizations, keyboard-navigable data tables, and responsive card layouts suitable for medical staff viewing on mobile tablets or desktop workstations.

Primary Focus: Complex layout organization, high contrast readability, and accessible data display.
